Privacy Policy

Effective date: September 24, 2026

My Twitch Chat History is a browser extension for reviewing the signed-in viewer's own Twitch message history and available public chat logs for other Twitch users when the viewer explicitly requests them. This policy explains what data the extension uses and where it goes.

Data the extension accesses

The extension accesses only the data needed to provide its user-facing features:

  • the signed-in viewer's Twitch account and public profile information;
  • the current Twitch channel;
  • the viewer's own message history, message count, and relationship information returned by Twitch;
  • public Twitch profile and channel-relationship information for a user whose card the viewer opens;
  • available public chat logs and log statistics returned by Zonian Logs for a selected Twitch username and channel; and
  • public global and channel emote metadata returned by 7TV.

The extension does not ask for or store the user's Twitch password. It does not access private Twitch whispers.

How the data is used

Message history and profile information are used only to display history cards, message counts, profile details, search results, and related features requested by the user. The developer does not use this data for advertising, profiling, analytics, credit decisions, or any unrelated purpose.

Public chat logs

When the viewer explicitly opens or searches another user's public logs, the extension sends that selected Twitch username and the current channel login to logs.zonian.dev. Zonian returns public channel-chat records and aggregate availability information. These records may be incomplete, may contain gaps, and may be unavailable when a user or channel has opted out.

The extension does not send Twitch credentials, private messages, the viewer's personal history, or arbitrary page content to Zonian.

Data stored by the extension

  • User-selected preferences are stored in Chrome Sync storage.
  • The detected Twitch theme and a temporary cache of public 7TV emote metadata are stored in local extension storage.
  • When a loaded in-page card is moved into a browser popout, its currently displayed context, messages, pagination cursor, search state, and reading position are temporarily written to Chrome session storage under a one-time random token.

The popout handoff is removed as soon as the popout consumes it. If it is not consumed, it becomes unusable after two minutes and is removed during later cleanup or when the browser session ends. The extension does not persist chat history as a permanent archive.

Network requests

The extension communicates directly with:

  • www.twitch.tv to obtain the viewer's own history and relevant public Twitch profile information using the active signed-in Twitch session;
  • logs.zonian.dev to obtain available public chat logs and log statistics for the selected username and current channel; and
  • 7tv.io to obtain public global and current-channel emote metadata.

These services receive the information required to respond to a request and standard connection information such as the user's IP address under their own privacy policies. My Twitch Chat History does not operate an analytics, advertising, tracking, or data-collection server.

Data sharing and sale

The developer does not collect, sell, or rent personal data. The extension transfers only the identifiers needed to provide a requested feature to Twitch, Zonian Logs, and 7TV, which process requests under their own privacy policies. The developer does not receive a copy of those requests or responses. Data is not transferred to data brokers, advertising networks, or unrelated third parties.

Permissions

  • storage is used for preferences, theme detection, the temporary emote cache, and the one-time popout handoff.
  • Access to https://www.twitch.tv/* is required to add the extension interface and retrieve Twitch history and profile information.
  • Access to https://logs.zonian.dev/* is required to retrieve available public chat logs that the viewer explicitly opens or searches.
  • Access to https://7tv.io/* is required to display supported 7TV emotes.

Your choices

Preferences can be returned to their defaults from the extension popup. Removing the extension deletes its local extension data. The developer has no server-side copy of message history or settings to retain or delete.

Chrome Web Store Limited Use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

  • User data is used only to provide or improve the extension's single purpose and user-facing features.
  • User data is not transferred except as necessary to provide those features, for security purposes, to comply with applicable law, or as otherwise allowed by the policy.
  • User data is not used or transferred for personalized advertising, retargeting, or credit decisions.
  • Humans are not allowed to read user data unless the user explicitly shares specific information for support, or access is required for security or legal reasons.

Changes to this policy

This policy may be updated when the extension's features or data practices change. The effective date at the top of this page will be updated at the same time.
