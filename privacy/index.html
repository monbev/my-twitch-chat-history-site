Privacy Policy

Effective date: October 5, 2026. Covers version 1.2.0 and the project website.

My Twitch Chat History is a browser extension for reviewing the signed-in viewer's own Twitch message history and available public chat logs for other Twitch users when explicitly requested. This policy explains what data the extension uses and where it goes.

Data the extension accesses

The extension accesses only the data needed to provide its user-facing features:

  • the signed-in viewer's Twitch account and public profile information;
  • the current Twitch channel;
  • the viewer's own message history and message count in that channel;
  • available public chat logs for a selected user in the current channel, requested by the viewer;
  • indexed role counts, channel lists and available role dates from Roles.tv, only when the viewer chooses to look them up and grants optional access;
  • account creation, follow, cumulative subscription tenure, and ban information when Twitch provides it; and
  • public global and channel emote metadata returned by 7TV.

The extension does not ask for or store the user's Twitch password. It does not access private Twitch whispers.

How the data is used

Message history and profile information are used only to display the history card, message count, profile details, and related features requested by the user. The developer does not use this data for advertising, profiling, analytics, credit decisions, or any unrelated purpose.

Data stored by the extension

  • User-selected preferences are stored in Chrome Sync storage.
  • The detected Twitch theme and a temporary cache of public 7TV emote metadata are stored in local extension storage.
  • Requested public role counts and channel lists are cached in extension memory for up to ten minutes, with a limit of 100 cached responses. Loaded role lists also remain in the open card until it is closed or reloaded.
  • When a loaded in-page card is moved into a browser popout or full tab, its currently displayed context, messages, pagination cursor, search and roles view state, and reading position are temporarily written to Chrome session storage under a one-time random token.

The viewer handoff is removed as soon as the new viewer consumes it. If it is not consumed, it becomes unusable after two minutes and is removed during later cleanup or when the browser session ends. The extension does not persist chat history as a permanent archive.

Network requests

The extension communicates directly with:

  • www.twitch.tv to obtain the viewer's own history and related account information using the active signed-in Twitch session; and
  • 7tv.io to obtain public global and current-channel emote metadata;
  • logs.zonian.dev to retrieve available public chat logs for the selected user and channel; these logs may be incomplete and opt-outs are respected;
  • roles.tv to retrieve indexed role counts and channel lists after an explicit lookup and optional permission approval. The requested public Twitch login, selected role and pagination/filter parameters, and standard connection information are sent to this independent service. Indexed records may be incomplete or outdated. Loading channel avatars may contact Twitch's public image CDN.

These services receive the information required to respond to a request and standard connection information such as the user's IP address under their own privacy policies. My Twitch Chat History does not operate an analytics, advertising, tracking, or chat-history collection server. Voluntary support reports use the separate service described below.

Data sharing and sale

The developer does not collect chat history for analytics, advertising, or sale. Voluntary support reports are handled separately as described below. Data is not transferred to data brokers or advertising networks.

Voluntary support reports

The support page lets you deliberately send a problem description, an optional contact for a reply, an optional extension version, and optional support information. Nothing is sent until you submit the form and consent. The extension does not automatically attach messages, cookies, tokens, account names, screenshots, or chat history.

The delivery service uses Cloudflare Workers to validate and forward your report to the developer through Telegram. Cloudflare Turnstile performs anti-spam verification. These providers receive the report or verification information needed for their respective functions, along with standard connection data, under their own privacy policies. Never include passwords, authentication tokens, cookies, or private messages.

The handler has no report database and does not log report contents or IP addresses. A short-lived hash of the connecting IP is used for rate limiting. Reports remain in the developer's Telegram support chat while needed to handle the issue. You may request deletion by contacting the developer through support; provider-managed records are subject to each provider's policies.

A public GitHub issue is an alternative. Anything you post there is public.

Voluntary donations and website preferences

The donation page links to a monobank Jar that supports the developer's work. Clicking the payment link opens monobank in a new tab. Payment information is handled by the bank under its own policies, not collected by this website or extension. Donations are optional and do not unlock features.

The donation page also displays public Binance receiving addresses and locally hosted QR codes for optional cryptocurrency support. Copying an address does not connect a wallet or initiate a payment. The website does not query balances, transactions or exchange APIs. Transfers are handled by the sender's wallet or exchange and Binance under their own policies; blockchain transactions may be public. No private keys or exchange credentials are collected.

The website stores only your manually selected language in this browser's local storage. You can change it using the language selector or remove the preference by clearing this site's storage. The website does not use analytics or payment-tracking widgets.

Permissions

  • storage is used for preferences, theme detection, the temporary emote cache, and the one-time viewer handoff.
  • Access to https://www.twitch.tv/* is required to add the extension interface and retrieve the viewer's own Twitch information.
  • Access to https://7tv.io/* is required to display supported 7TV emotes.
  • Access to https://logs.zonian.dev/* retrieves public logs only when requested.
  • Optional access to https://roles.tv/* retrieves indexed public role counts and channel lists only after an explicit lookup. You may decline or revoke this permission without disabling message history.

Your choices

Preferences can be reset from the extension popup. Removing the extension deletes its local extension data. The developer has no automatic server-side copy of message history or settings. Any information you voluntarily send for support is handled as described above.

Chrome Web Store Limited Use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

  • User data is used only to provide or improve the extension's single purpose and user-facing features.
  • User data is not transferred except as necessary to provide those features, for security purposes, to comply with applicable law, or as otherwise allowed by the policy.
  • User data is not used or transferred for personalized advertising, retargeting, or credit decisions.
  • Humans are not allowed to read user data unless the user explicitly shares specific information for support, or access is required for security or legal reasons.

Changes to this policy

This policy may be updated when the extension's features or data practices change. The effective date at the top of this page will be updated at the same time.
