# My Twitch Chat History site

Public website, privacy policy, and support pages for the My Twitch Chat History Chrome extension.

[Install the extension from the Chrome Web Store](https://chromewebstore.google.com/detail/gigogimnabnbbdffaocnnolakaggnahp)

The site is intentionally static and contains no analytics, cookies, or third-party scripts.

## Pages

- `/` — product overview
- `/privacy/` — privacy policy
- `/support/` — support and troubleshooting
